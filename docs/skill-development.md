# Developing a skill

1. Choose one cohesive engineering task and define activation boundaries.
2. Create skills/<slug>/SKILL.md with required YAML frontmatter.
3. Include all validated headings.
4. Add actionable workflows, domain-specific security rules, failure handling, tests, and examples.
5. State expected outputs and limitations.
6. Add the skill to skills/INDEX.md or run scripts/generate_index.py.
7. Run validators and link checker.
8. Request domain review.

A good skill changes agent behavior: it causes inspection, repeatable steps, failure handling, security enforcement, and evidence-based reporting.
