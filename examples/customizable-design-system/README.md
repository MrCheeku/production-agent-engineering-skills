# Customizable design system example

Open index.html in a modern browser. No build step or external assets are required.

Includes semantic color/spacing tokens, light/dark themes, reusable button styles, responsive cards, labelled input, native dialog, visible focus, and reduced-motion handling.

Before production, add automated accessibility checks, browser support testing, visual regression coverage, localization, and a documented component API. Verify contrast for final brand token values.
